- このプロジェクトの目的は、スケールしやすく様々な目的に使える模範的なテンプレートとなるリポジトリをつくることです。
- 保守性やスケールのしやすさの観点からプロジェクト構造を設計する必要があります。
- Backendは、GoとPocketBase v0.39+を使い、frontendは、solid.js + tailwind v4を使います。
- このアプリは、SPA＋CSRの個人向けのアプリです。
