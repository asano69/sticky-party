無限の拡張性：付箋の中に次のコンテンツを表示できます。
1. 外部のiframeコンテンツ（Youtube, Google Map, ...）
2. 拡張機能オリジンのコンテンツ
3. sticky-partyサーバオリジン経由でプロキシされたコンテンツ
4. サーバサイドでレンダリングされたコンテンツ (codeブロック)


## 新しいサーバサイドのレンダラを追加する方法

1. レンダリングしたいシグネチャ（コードフェンスにおける言語指定）を決める。
2. バックエンドにおいて、annotation保存にフックして、コードブロックを評価し、rendersコレクションに保存するコードを実装する。
3. 付箋プレビュー時に、renderキャッシュをあてはめる
4. GCを実装する
